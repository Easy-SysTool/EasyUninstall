卸载安全，设计优先

Safety by Design

安全性は設計から

EasyUninstall 在设计上严格约束卸载行为，不做任何"粗暴删除"。

EasyUninstall strictly constrains uninstall behavior — no brute-force deletion, ever.

乱暴な削除は一切行わない、厳格な設計ポリシー。

绝不

Never

絶対にしない

  • 直接删除软件安装目录、用户文件或注册表
  • Directly delete install directories, user files, or registry
  • インストール先やレジストリを直接削除しない
  • 将 UninstallString 交给 cmd.exe / PowerShell 执行
  • Hand UninstallString to cmd.exe / PowerShell
  • UninstallString を cmd や PowerShell に渡さない
  • 使用字符串拆分猜测可执行文件与参数
  • Guess executables and args by string splitting
  • 文字列分割で実行ファイルを推測しない

安全措施

Safeguards

安全対策

  • 独立命令解析器：拒绝 cmd / powershell / mshta 等危险宿主，可执行文件必须真实存在
  • Dedicated command parser rejects dangerous hosts (cmd / powershell / mshta…); executables must really exist
  • 専用パーサーが危険なホストを拒否し、実行ファイルの存在を検証
  • MSI 仅接受 MsiExec.exe /X{GUID} 模式并校验 GUID 格式
  • MSI accepts only MsiExec.exe /X{GUID} with GUID validation
  • MSI は MsiExec.exe /X{GUID} 形式のみ許可
  • 命令有歧义时禁用卸载按钮并说明原因；卸载后重新扫描确认
  • Ambiguous commands disable the button; results confirmed by re-scan
  • 曖昧なコマンドは無効化し、再スキャンで結果確認
  • 默认无需管理员权限，仅在需要时按需提权（UAC）
  • No admin rights by default; on-demand UAC elevation only when required
  • 既定で管理者権限不要、必要時のみ UAC 昇格

从源码构建

Build from Source

ソースからビルド

需要 .NET 8 SDK 与 Windows App SDK 工作负载。

Requires the .NET 8 SDK and the Windows App SDK workload.

.NET 8 SDK と Windows App SDK が必要です。

# Clone & build (MSIX package generated automatically)
git clone https://github.com/yoyo-coding/EasyUninstall.git
cd EasyUninstall
dotnet build src/EasyUninstall/EasyUninstall.csproj -c Release -p:Platform=x64

# Run tests
dotnet test tests/EasyUninstall.Tests/EasyUninstall.Tests.csproj -p:Platform=x64

生成的 MSIX 位于 src/EasyUninstall/AppPackages/；完整签名与安装步骤见 README。 The MSIX lands in src/EasyUninstall/AppPackages/; see the README for signing and install steps. MSIX は src/EasyUninstall/AppPackages/ に生成されます。詳細は README を参照。
